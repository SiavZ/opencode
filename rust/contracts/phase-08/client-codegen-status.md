## Explicit remaining scope

This delivers Rust client operation/type generation from Protocol. It does not implement native HTTPS/browser fetch adapters, cancellation policies, SSE reconnect/legacy malformed-frame fallback, or WebSocket connection management. SSE operation frame decoding and WebSocket request descriptors are explicit low-level APIs, not those runtime policies. TS Promise/Effect output regeneration is not implemented here. Unknown SchemaIR nodes remain unknown JSON rather than invented typed parity. Full phase-08 or product parity is not claimed.
