## Client public API (`opencode_client`)

- `errors::ClientError { reason: ClientErrorReason, status, cause }`, reasons `Transport | UnexpectedStatus | UnsupportedContentType | MalformedResponse` (baseline `packages/client/src/generated/client-error.ts:1`).
- `errors::ApiError<E> = Declared { status, body: E } | Client(ClientError)`. A declared error status always decodes to `Declared`, never to `ClientError` (baseline `client.ts:171-177`).
- `transport::RequestDescriptor { method, path, query, headers, body, success_status, declared_statuses, empty }` (baseline `client.ts:129-138`), bracket query serialization (`client.ts:993-1004`).
- `transport` adapters: native reqwest, browser fetch (cfg `wasm32`). Caller cancellation is drop-based (native) / AbortController (wasm).
- SSE: two explicitly separate policies.
  - Current (`events.subscribe`, session events): lazy open, no reconnect, ignores `id`/`retry`/`event`, CRLF split handling, 1,048,576 char buffer cap -> `MalformedResponse`, reader cancel on drop (`client.ts:192-247`).
  - Legacy (`/event`, `/global/event`): parses `id`/`retry`/`event`, reconnects with `Last-Event-ID` and retry delay, normal EOF ends the stream, malformed JSON yields the raw string (`packages/sdk/js/src/v2/gen/core/serverSentEvents.gen.ts:95-238`).
- PTY WebSocket: ticketed `pty.connectToken` then `pty.connect` socket, native tokio-tungstenite, wasm `web-sys::WebSocket`.
- `current::*`: one typed method per current operation, grouped with ClientApi aliases (`packages/client/src/contract.ts:20-53`), including the three generator-omitted operations `fs.read`, `pty.connect`, `pty.connectToken`.
- `legacy::*`: one typed method per legacy v2 operation (`packages/sdk/js/src/v2/gen/sdk.gen.ts`) and root gen (`packages/sdk/js/src/gen/sdk.gen.ts`).
- Rust operation modules are generated by `xtask codegen` (emit/rust.rs) from the same IR as the JS outputs.

## Codegen contract (`cargo xtask codegen`)

- Input: `codegen::contract` IR via a `Source` trait. Authoritative source is the opencode-protocol registry (Phase 06). Until it lands, the source is a JSON IR snapshot captured from the TS baseline in `contracts/phase-08/fixtures/ir/`.
- Outputs, each with a byte-level diff test against the checked-in baseline file:
  - `packages/client/src/generated/{client.ts,types.ts,index.ts,client-error.ts}` (Promise) and `generated-effect/{client.ts,index.ts,client-error.ts}` (imported Effect), plus `.httpapi-codegen.json` manifest.
  - `packages/sdk/openapi.json`, `packages/sdk/js/src/gen/**`, `packages/sdk/js/src/v2/gen/**`.
- Determinism: two runs produce identical bytes. No node/bun at generation time.
- Writer: manifest-owned files only, rejects absolute/`..`/case-colliding paths and symlinks, removes stale manifest entries. Not atomic across the directory (same as baseline `httpapi-codegen/src/index.ts:710-768`), interrupted generation is recovered by rerunning.
- Tests never write into `packages/`. Generation into `packages/` happens only on explicit request.

## sdk-embedded contract

- `Embedded` composes the real server router and runtime in-process with auth disabled (baseline `packages/sdk-next/src/opencode.ts:10-43`, `packages/server/src/routes.ts:47-48`), shares location-owned tools and permissions, joined disposal.
- Subprocess launcher: serve/TUI flags, config env, stdout readiness line, timeout, abort and process-tree cleanup (baseline `packages/sdk/js/src/server.ts:22-134`, `process.ts:5-30`).
- Until server/runtime crates expose the needed APIs, the in-process facade returns `EmbedError::NotYetPorted { component }` (tested), see status.md.
