# Empty-host baseline census

Generated by `cargo xtask parity-census`. No fixtures or expected failures are changed.

430 captured cases, 384 ledger mismatches, 46 matches. These counts describe
`app::router(Services::default(), ServerConfig::full_host(..))`, NOT the production Process.
`not-mounted` and `not-ported` identify absent routes/services in that host; they do not
prove that the corresponding domain implementation is absent from production.
`status` and `body` identify observed empty-host wire differences, also requiring production replay.

Strict public check for EVERY row: `cargo test --locked --offline -p opencode-runtime --test strict_replay -- --ignored --nocapture`.
API/bat reviews the HTTP contract for all domain-owned rows. No ledger entry excuses a strict failure.
